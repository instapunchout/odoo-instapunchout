# InstaPunchout for Odoo

cXML, OCI, EDI and IDS for Odoo eCommerce. One branch per Odoo version (`17.0`, `18.0`, `19.0`, `20.0`), module in `instapunchout/`.

The module is free (LGPL-3). It requires an InstaPunchout subscription: a one-time setup fee and a yearly license per buyer connection. Contact info@instapunchout.com.
